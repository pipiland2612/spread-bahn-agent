# Level 4 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Measure competitive quotes and enter a validated Level 4 policy on the leaderboard.
**Architecture:** Pure quote planner reuses option-specific feasibility. Desk integrates it only at Level 4; settings/checkpoints preserve experiments.
**Tech Stack:** TypeScript, Node native tests, official client, no dependencies.
**Spec:** docs/superpowers/specs/2026-11-14-level-4-design.md

## Global Constraints

Preserve Levels 1–3 and vendor files; integer cents; no Levels 5–8. Three tuning/three holdout seeds, >=95% on time each week, positive aggregate margin, complete evidence and zero refused actions. Four active worlds maximum. No routine approval questions under user authorization.

## Review Focus

An infeasible first option must not hide a feasible later option. Margin filter must use quoted price. Expired requests cannot receive decline quotes. Resume must preserve quote settings and reject missing ones. First/list-price comparator and candidates must use identical dispatch settings.

### Task 1: Quote decisions

Create src/quotes.ts and tests/quotes.test.ts. Export QuoteSettings, validateQuotes and planQuote(model, request, now, settings). Tests first: later-option feasibility, price rounding, actual-price margin rejection, high decline quotes, expiration and invalid settings. Run node --test tests/quotes.test.ts and observe failure; implement; run npm test; commit.

### Task 2: Runner and recovery

Modify settings, fees, network and runner for Level 4. Tests first for Level 4 settings, no higher levels, strict quote CLI validation and resume preservation, Desk later-option posting and Level 3 unchanged. Persist quoteSettings everywhere settings are saved. Add practice:level4/board:level4 scripts. Run suite, syntax and whitespace checks; commit.

### Task 3: Evidence and delivery

Run matched tuning, select eligible winner, run independent holdouts. Record measured results and any deviation in execution report. Fresh whole-branch reviewer checks implementation and evidence; fix important findings with RED/GREEN tests. Play up to five available ranked weeks under the validated policy. Save leaderboard response, update README/strategy/results, push isolated branch and open PR. Do not merge.
